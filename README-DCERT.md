# LifePick dcert 업로드 안내

압축 해제 후 보이는 `dcert` 폴더와 안내 파일 전체를 GitHub 저장소 최상위 Upload files 화면에 한 번에 드래그하세요.

페이지 경로: https://lifepick.life/dcert/

주요 기능:
- 자격증명·설명·연관키워드 실시간 검색
- 전체 및 카테고리 버튼 클릭 시 결과 영역 자동 이동
- 검색·필터 시 빈 과정 구역 자동 숨김
- PC 우측 및 모바일 하단 CPA/CPS 고정 영역

- 과정명은 제공된 PDF 카드 표기를 기준으로 정리했습니다.
- PC 우측 고정영역은 크기를 유지한 채 상단으로 올렸습니다.
